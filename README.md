# Autonomous Engineering Agent

An AI engineering agent exploring how far an AI can participate in the
software engineering lifecycle.

## Vision

Software engineering is more than writing code.

An engineering task often requires understanding an existing system,
planning a solution, implementing changes, investigating failures,
testing the result, and verifying that the solution works as intended.

This project explores whether an AI agent can participate in that
complete workflow with minimal human intervention.

## Workflow

Task
  ↓
Understand
  ↓
Plan
  ↓
Develop / Investigate
  ↓
Test
  ↓
Iterate
  ↓
Verify
  ↓
Human Review

Build Day in Bhopal.

The goal is to build a working prototype during the event and explore
the capabilities of Claude in an end-to-end engineering workflow.

## Status

🚧 Concept / Pre-Build

## Project Goal

The goal is not simply to generate code, but to explore an agent that
can understand engineering context, take action, validate its work,
and iterate toward a verified result.
